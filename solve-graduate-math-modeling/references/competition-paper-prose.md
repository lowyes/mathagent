# 数学建模竞赛正文：精炼、证据化与去百科化

## 使用边界

在起草或压缩问题重述、问题分析、模型建立、结果分析和模型评价时读取本文件。优秀论文仅用于观察章节组织、证据节奏和版面密度；不要复制其原句、具体模型组合、数值、图表或未经核验的医学与行业背景。获奖论文也可能存在长背景、教材式定义或指标使用不严谨的问题，应取其结构长处而不是整篇模仿。

## 竞赛正文的核心任务

竞赛论文不是算法百科，也不是文献综述。评委阅读每个小问时，应能连续找到：

1. 题目要求输出什么；
2. 数据或约束造成什么困难；
3. 为什么选择当前方法；
4. 模型如何在本题上被实例化；
5. 结果是多少；
6. 结果是否可信、最终回答是什么。

一个段落至少承担“任务、方法、证据、解释、边界”中的一项。若整段只介绍模型历史、通用优点或宏观意义，删除或压缩。

## 各章节的职责

### 问题重述

- 背景通常控制为一至两个自然段，只保留理解任务边界所需的信息。
- 不从搜索资料扩写疾病史、产业史或算法发展史；外部事实若不是后续模型输入、约束或评价依据，不进入正文。
- 按题面顺序重述输入、输出和小问关系，不提前写求解结果，也不逐句改写题目。

### 问题分析

- 不重复问题重述。写清“数据对象—主要困难—处理路径—上下游依赖”。
- 优先指出泄漏、缺失、不平衡、时序、量纲、约束、评价口径等会改变模型选择的因素。
- 一张总体流程图可代替重复的步骤叙述；图后只解释关键分支和数据流。

### 模型建立

先写选择依据，再写数学结构。推荐顺序为：

> 本题困难或数据特征 → 候选方法需要具备的能力 → 选择当前模型的理由 → 本题中的输入、输出和参数 → 核心公式 → 求解协议。

模型介绍不得以“某模型由某人在某年提出”开场，除非提出时间或版本本身影响复现。不要写“是一种广泛应用的方法”“具有较好的性能”等无法支持本题选择的通用评价。

### 结果与验证

结果段采用“比较对象—关键数字—变化幅度—原因解释—决策影响”的次序。例如：

> 在相同病灶级划分下，加入BiFPN后验证集Accuracy由0.831升至0.838，综合指标J由0.685升至0.701。因此多尺度融合得到保留；但B2在224像素下退化，说明扩大骨干不能脱离输入分辨率单独判断。

没有统计检验时不用“显著”。不要以“效果较好”“验证了可行性”替代真实指标、区间或约束满足情况。

## 算法介绍篇幅门

算法原理只保留理解本题实现和创新所必需的内容：

- 基线或常见算法：通常用一个选择依据段、一条核心公式和一个参数来源段即可。
- 核心改进算法：可展开其结构、目标函数、约束、伪代码和流程图，但每一部分必须对应真实代码或结果。
- 深度网络：重点写输入尺度、骨干输出、改动模块、损失、冻结/微调策略和决策规则；不逐层复述公开架构手册。
- 同一机制只解释一次。图已经清楚展示的层级和连接，正文只解释关键设计及其作用。
- 公式必须在后文被使用、估计、求解、验证或解释。仅用于展示知识储备的公式删除。

“一个段落加一条核心公式”是常见基线，不是机械上限；复杂度应由本题实际贡献决定。

## 从百科式写法改为本题写法

不推荐：

> EfficientNet由Google于2019年提出，其核心贡献是复合缩放理论。传统卷积神经网络通常沿深度、宽度或分辨率单一维度扩展。

推荐：

> 训练集规模有限，而皮肤病变的判别线索同时包含局部纹理和整体形状。本文选用参数量较小的EfficientNet-B0作为基线骨干，并利用ImageNet预训练降低从头训练的过拟合风险；随后只通过受控消融判断BiFPN、骨干容量和输入分辨率是否带来增益。

不推荐：

> 交叉熵是一种广泛应用于分类问题的损失函数，能够衡量真实分布与预测分布之间的差异。

推荐：

> 普通交叉熵不修正七类样本数量差异，因此作为无重加权基线；温和加权交叉熵根据训练集类别频数提高小类权重，Focal Loss进一步降低易分样本的贡献。三者使用相同数据划分和训练协议，以隔离损失函数的影响。

## 段落功能审计

完成一章后，为每个自然段标记一个主要功能：

- `T`：任务或困难；
- `M`：模型、公式或实施；
- `E`：数据、表图或数值证据；
- `I`：解释、比较或机制；
- `B`：适用边界、风险或直接回答。

连续两个以上段落只有通用 `M` 而没有本题输入、参数或证据，通常属于教材式堆砌。连续多个 `T` 段则说明问题重述和问题分析可能重复。`E` 后没有 `I/B`，说明论文只报数没有完成建模解释。

## 精炼流程

1. 删除模型提出者、年份、发展史和与本题无关的排行榜数据。
2. 合并重复定义；术语在第一次出现时解释一次。
3. 把“方法可以做什么”改为“本文具体怎样做、输入输出是什么”。
4. 把形容词换成比较基准和数值，例如用“提高1.6个百分点”替代“明显提升”。
5. 将参数来源、验证规则和结果移到对应模型旁边，减少读者前后查找。
6. 渲染PDF，检查是否因删除文字造成孤立标题、大面积空白或图表失去解释。

## 版面与篇幅

一等奖样本的总页数差异很大，不能用总页数判断质量。应按信息价值分配版面：背景和通用知识从紧，核心建模、真实结果、消融、误差与结论从实。比赛有页数上限时优先删除百科内容、重复流程和装饰性图表，不压缩关键证据字号。

## 自动扫描的定位

可运行：

```powershell
python scripts/audit_paper_prose.py <论文目录或TeX文件>
```

脚本只定位长段落、长句、百科式开头和高频套话，不自动改写，也不以关键词数量判定论文好坏。逐条结合上下文判断：必要的定义保留，不能服务本题推理的内容压缩。

# 工作区与文件归属

## 目录结构

```text
项目/
├── 题目/                         # 原始赛题，只读保留
├── 数据/                         # 原始附件，只读保留
├── 项目清单.json                 # 问题/小问、依赖与交接总表
├── problem-spec.json             # 新版：题面任务蓝图与动态质量门来源
├── 求解计划.md
├── 求解/
│   ├── 公共/
│   │   └── 代码/                 # 仅放真正复用的函数或模块
│   ├── 问题一/
│   │   ├── 小问1/
│   │   │   ├── 代码/
│   │   │   ├── 图/
│   │   │   ├── 结果/
│   │   │   └── 小问清单.json
│   │   └── 小问2/ ...
│   └── 问题二/ ...
├── 论文/
│   ├── main.tex
│   ├── graduate-modeling.cls
│   └── sections/                   # Skill 内部模板统一使用 ASCII 文件名
└── 交付/                         # 最终 PDF、附件和提交清单
```

## 归属规则

代码、图和结果以“产生该证据的小问”为唯一归属单位。一个文件不得同时归属于两个小问；确需跨小问使用时，保留单一源文件，并由下游小问通过交接契约读取。

公共目录只接收不含具体题目结果的复用代码。数据清洗脚本若只服务于问题一小问1，仍放在该小问的代码目录。全题统一的数据字典、解析器或通用绘图样式可以放公共代码目录。

每个 `小问清单.json` 至少维护：任务类型、建模契约、方法与参数血缘、文献适用性、按需实验、验证评估方法、按需模型比较、发现与决策、结论—证据矩阵、四阶段质量门、目标输出、单位、输入、依赖、代码文件、图文件、结果文件、核心指标、随机种子、运行状态、验证状态和直接结论。路径一律相对于项目根目录。

字段清单以 `scripts/validate_project.py` 为唯一权威：它定义每个键的名称、类型、必填条件和枚举取值，本文与其他参考文档只解释这些字段为什么存在、如何填得可信。两者若不一致，以校验脚本为准，并把文档改回与脚本一致。字段的用途与填写要求见 [evidence-workflow.md](evidence-workflow.md)。

`项目清单.json.paper_profile` 记录结构版本、数据组织 Profile、假设/符号合并方式、公共数据章和模型评价章是否启用、正式论文章节角色及 `source_order`；每个问题条目另记 `analysis_mode`。默认采用 `mode=default` 并按这些决策校验实际源文件链；当届官方模板或用户明确要求改变语义顺序时，使用 `official_override` 或 `user_override`，并登记 `override_reason` 与 `override_reference`。模板资源与生成后的论文源文件均使用 ASCII 文件名，避免 ZIP、Git 和跨平台工具把中文文件名转义为 `#Uxxxx`；正文标题仍使用中文。

初始化脚本写入的占位值不是合法终值。`status`、`validation.status`、`literature_review.applicability`、`model_comparison.applicability` 和四个质量门的 `status` 都可能以 `pending` 起步，必须在小问完成前按任务类型改写成校验脚本接受的取值。

## 跨小问交接

下游小问使用上游输出时，在 `项目清单.json` 的 `handoffs` 数组中登记一条记录：

```json
{
  "from": "求解/问题一/小问2",
  "to": "求解/问题二/小问1",
  "fields": [
    {"name": "日均客流量", "unit": "人/天", "granularity": "门店×日"}
  ],
  "quality_flags": "缺失日按前后七日中位数补齐并置 imputed=1；补齐比例超过 15% 视为不可用",
  "fallback": "上游不可用时退回问题一小问1的月度均值并在正文标注口径下降"
}
```

`from` 和 `to` 必须是已登记的小问目录且不相同，`fields` 至少一项且每项都要有 `name`、`unit`、`granularity`，`quality_flags` 与 `fallback` 不得为空。最终校验会反查：小问清单里凡是指向另一个小问目录的 `dependencies`，都必须有方向一致的 `handoffs` 记录。

禁止下游静默重算一个口径不同的同名指标。

## 图表路径

从 `论文/` 目录编译 `main.tex` 时，即使图片命令写在被引入的章节文件中，路径仍相对于主编译目录。引用示例为：

```latex
\includegraphics[width=0.82\textwidth]{../求解/问题一/小问1/图/误差分布.pdf}
```

不要把图片复制进论文目录来掩盖归属关系。

# 优秀范文风格迁移

当用户提供获奖论文、往届范文或指定写作样例时使用本规则。目标是提取可迁移的表达组织方式，形成当前项目的 `论文/style-card.md`；范文不是事实来源，也不是模型选择指令。

## Style Card 提取范围

只观察并概括以下维度：

- 方法如何由当前数据困难和选择标准引出；
- 公式前如何界定对象，公式后如何解释变量和现实含义；
- 结果段如何安排比较对象、关键数字、边界和决策；
- 任务、方法、结果、验证和结论之间如何逐层递进，表与图连续出现时如何说明证据分工；
- 小问之间如何承接上游结果；
- 目录如何随公共数据、任务差异和总结需要发生变化；
- 标题粒度、自然段主要功能和常见段落长度；
- 图、表、公式与正文的大致密度及各自承担的证据任务；
- 摘要逐问呈现方法、结果和直接结论的节奏。

不得从范文迁移：

- 具体算法、参数、阈值、数据划分和实验协议；
- 数字、评价结果、业务事实、假设和因果结论；
- 只适用于范文题目的对象、符号和专业术语；
- 原句、连续句式或具有辨识度的表述。

## 生成 Style Card

`论文/style-card.md` 保持简短，并明确区分三类内容：

```text
参考边界：仅学习结构、证据节奏和标题粒度

## 范文共同特征
- 多篇范文都出现、可作为一般写作规律的证据组织方式

## 可选择变体
- 不同范文之间互有差异的目录、标题、图表密度和分析位置

## 当前赛题采用
- 结合当前题面、任务蓝图和锁定结果后实际选择的结构与节奏

## 参考来源
- 文件名、页码或可定位范围

禁止迁移：范文模型、数值、假设、结论和原句
```

不得把只在一篇论文出现的形式直接写进“共同特征”。至少两篇相互独立的范文共同出现且与当前赛题不冲突，才可考虑上升为一般规则；否则放入“可选择变体”。schema v2 中每个来源登记 `id`、题名、页码/章节定位和文件路径或正式引文；每条共同特征用 `supported_by` 指向至少两个来源，每条变体至少指向一个来源，当前赛题采用项则写明 `reason`。不要用“某一等奖论文”这类无法回看的模糊来源。

```json
{
  "style_transfer": {
    "enabled": true,
    "sources": [
      {"id": "A", "title": "一等奖论文甲", "locator": "摘要第1--2页", "path_or_citation": "D:/references/award-a.pdf"},
      {"id": "B", "title": "一等奖论文乙", "locator": "目录第3--4页", "path_or_citation": "D:/references/award-b.pdf"}
    ],
    "card": {
      "common_features": [{"statement": "摘要逐问给出方法、数字与结论", "supported_by": ["A", "B"]}],
      "variants": [{"statement": "模型评价章可独立或就地收束", "supported_by": ["A"]}],
      "current_choices": [{"statement": "各问就地评价", "reason": "当前小问已形成相邻证据闭环"}]
    }
  }
}
```

Style Card 必须与当前题面、项目清单和锁定结果共同输入写作过程。发生冲突时，当前题面和证据优先；不得为了“像范文”改变实验结果、问题顺序或模型事实。

## 写后对照复核

schema v2 项目在初始化时同时生成 `论文/style-review.md`，此时项目清单中的 `style_transfer.status` 只能是 `card_ready`。论文完成并编译后，再以当前 PDF 和正式 TeX 为对象，逐项比较：

1. 摘要逐问覆盖与关键数字；
2. 题面映射与标题粒度；
3. 模型引入与参数来源；
4. 结果、验证与模型取舍；
5. 段落、图表与跨小问递进及解释边界；
6. 图表密度与最终 PDF 版面。

每项都要登记范文页码、本论文位置、发现的差距和实际处理；没有差距时也要说明核验依据，不写空泛的“与范文一致”。六项完成后，将复核文件标记改为 `REVIEW_STATUS: checked`，在项目清单 `style_transfer.checks` 中登记同样的六项证据，再把 `status` 改为 `checked`。最终校验只把这一记录视为“完成了对照复核”，不把它解释成获奖保证。

## 写后反查

1. 每段能否指出其任务、方法、证据、解释或边界功能？
2. 是否保留了范文节奏，却没有复制范文事实和句子？
3. 是否因模仿标题而重新产生机械清单式结构？
4. 是否把范文某一种目录误写成所有赛题的固定骨架？
5. 结果解释是否没有超出当前实验支持范围？
6. 摘要、正文与结论是否仍读取同一组锁定结果？
7. 只读标题、段落首尾句和图表题注时，是否仍能恢复“困难—方法—结果—验证—回答”的推理链？

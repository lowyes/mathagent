# 验证评估与正文闭环

## 核心原则

验证评估不是独立的知识介绍，而是模型论证链的一部分。每种方法都按以下顺序紧邻被验证对象书写：

1. **验证对象**：明确验证哪个模型、参数、约束、结果或结论。
2. **选择理由**：说明该方法能发现什么风险，以及为什么适合当前数据结构和任务。
3. **简要定义**：首次出现时定义必要概念、符号、指标方向和接受判据，不展开与本题无关的教材内容。
4. **本题协议**：写明实际样本单位、数据划分、分组/分层/时间顺序、扰动范围、重复次数、随机种子、基准情景、泄漏控制或停止条件。
5. **实际结果**：引用真实结果表或图，给出字段、行、键或工作表定位。
6. **解释与决策**：说明结果支持、否定或限定了什么，以及是否改变模型选择、参数、结论强度、fallback 或适用边界。

只给方法公式而没有本题结果、只给结果而没有判断标准、只写“效果良好”而没有决策影响，均不算完成验证。

## 不同方法必须结合的内容

- **交叉验证或样本外验证**：样本单位、折数、分层/分组规则、时间顺序、预处理是否在折内拟合、逐折指标、均值与波动、模型选择规则。
- **混淆矩阵及分类指标**：正负类业务含义、TP/FP/FN/TN 对应风险、指标公式与方向、阈值来源、实际矩阵或样本外预测、误报与漏报对结论的影响。
- **误差或残差分析**：误差定义、分组口径、偏差结构、异常点处理、误差是否满足模型假设，以及对预测区间或结论边界的影响。
- **敏感性与鲁棒性**：被扰动参数、基准值、来源、扰动范围、联合或单因素方式、输出变化、稳定区间与失效边界。
- **可行性与最优性**：约束残差、可行率、求解状态、最优性 gap 或小规模精确对照，以及“最优/近似/较优”措辞依据。
- **收敛与数值验证**：迭代停止条件、网格或步长、重复次数、误差阶或收敛曲线、失败运行和 fallback。
- **不确定性、仿真或统计检验**：分布或假设、采样方式、重复次数、置信区间或显著性口径、多重比较处理和结论适用范围。
- **消融与基准对照**：移除或替换的模块、统一数据与指标、性能变化及其对创新点有效性的说明。

`type` 可使用：`out_of_sample`、`cross_validation`、`classification_metrics`、`error_analysis`、`residual_analysis`、`sensitivity`、`robustness`、`uncertainty`、`feasibility`、`convergence`、`optimality`、`ablation`、`benchmark`、`statistical_test`、`simulation_check`、`physical_boundary` 或 `other`。

每个已完成小问至少登记一种与任务相适应的验证方法。正文对应位置必须包含 `\label{paper_anchor}`；证据文件必须存在于所属小问结果目录并登记到 `result_files`。若一种方法验证多个模型，可共享一条记录，但必须在 `target` 和解释中明确覆盖范围。
